- Building correlated risk scores to reduce false positives
- Creating SOC dashboards with multiple visualization types
- Configuring scheduled alerts and trigger conditions
- Documenting detections with MITRE ATT&CK mapping
- Following a structured incident response workflow

## 🚀 How to Reproduce
1. Install Splunk Enterprise (free trial) → localhost:8000
2. Upload data/phishing_emails.log to a new index called phishing_lab
3. Set sourcetype as email_raw
4. Run any query from spl/detection_queries.md
5. Build the dashboard using the queries
6. Create a scheduled alert from Query 5
